# lazy-minecraft-server

A Minecraft server that shuts down when idle. Whenever offline a "Server is idle" MOTD will be displayed, attempting to connect 
will boot up the server and inform the client to retry the login.

[See demo here](https://github.com/goncalorazevedo/lazy-minecraft-server/issues/1)
